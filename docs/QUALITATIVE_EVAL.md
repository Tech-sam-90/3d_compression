## Caveat found on manual inspection (not measured by the script's own metric)

But reading across scans for a **fixed** instruction tells a different story: **Instruction B's output is nearly identical across `valid_131_a_1`, `valid_634_a_1`, and `valid_1_a_1`** ("No pneumothorax, pleural effusion or increased thickness was detected in both lungs. No suspicious mass or nodular space-occupying lesion is observed in the lung parenchyma of either lung."), only diverging slightly for `valid_382_c_2` and `valid_500_d_1`. **Instruction C** shows the same pattern even more strongly — near-identical "No lymph node was observed..." boilerplate across 4 of the 5 scans, despite ground-truth findings ranging from COVID-pattern bulla-bleb disease to pleuroparenchymal sequelae to cardiomegaly with aortic dilatation.

This echoes the Test 3 Part B scan-sensitivity issue already documented in `docs/DIAGNOSTIC_REPORT.md` (collapse rate 6.7% for this exact checkpoint under the default full-report instruction) — here showing up more strongly for the two narrower instructions than for the full-report instruction. Worth a follow-up Test-3-style Part B rerun specifically using Instructions B/C as the fixed instruction, rather than only the default "generate a full report" instruction Test 3 has used everywhere so far.
